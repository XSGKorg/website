# Contributing

1. Clone / fork this repository
```shell
git clone https://github.com/XSGKorg/website.git  
cd website
```

3. Start the development server with [bun](https://bun.dev)
```shell
bun install  
bun run serve
```

4. Make your changes

5. Submit a pull request

6. done.
